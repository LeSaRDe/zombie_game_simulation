1. The complete system

The live path separates ontology domain values, game rule calculation, committed state ownership and persistence. Functional React views remain backed by controller objects.

2. Persistent identity, typed state and roles

Human and Zombie are current AgentState variants. The same AgentIdentity survives conversion. Roles and model assignments are independent, and historical event payloads preserve earlier state values.

3. Rule calculation and state ownership

GameRuleSet never receives a Simulation, database or publisher. Its PlanningSession can mutate only an isolated draft and runtime branch. Typed plans cross the boundary to revision validation and atomic publication.

4. One atomic simulation transition

The ontology time phases and canonical random keys are unchanged. Rules produce a proposal without publication; the atomic persistence result determines whether the new typed world becomes visible.

5. Managed runs, HTTP and analysis

WorkspaceServices owns the application lifetime. Each run has one writer process. Read pools and exporters operate on committed history. Shutdown drains accepted work, closes readers/viewers, and reconciles run controls before service exit.

Open SVGEditable DOT

6. Persistence contracts and restart

State ownership is independent of storage. Memory live projections, durable SQLite journals and a fully independent in-memory contract backend implement the same transaction/read boundaries. Unsupported schema or implementation versions fail explicitly.

Open SVGEditable DOT

7. Snapshot isolation without whole-memory copies

Runtime snapshots retain immutable cells. Exact built-in trees use copy-on-write branches; custom or aliased Python graphs use per-agent opaque copies. Unread model memories retain stable cell identities. Queue forks stay concrete heap-compatible lists of immutable ScheduledTask values.

8. GUI objects behind functional React views

React still renders and subscribes. Controllers own requests, retries, generation checks, caches and cleanup. Canvas and Plotly drawing have dedicated owners. Exact rational values remain authoritative; rounded labels are presentation only.

9. Modeling, research and training

Extend behavior by implementing small contracts. Biological type, role, model assignment and persistent identity are separate. Model input has no global-state lookup. Learning keeps its existing pinned kernels and adds injectable orchestration.
